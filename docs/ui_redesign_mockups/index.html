Step 2 "Orchestration & Data Intel" — UI redesign mockups

Interactive reference mockups for the Step 2 layout redesign. These accompany docs/STORY9_STEP2_UI_REDESIGN.md. Open each in a browser and click around — sub-tabs, collapsible rows, and the master-detail rail are all live. Light-theme reference renders; the live app is dark-themed.

Mockup 1 — Sub-tabs + KPI strip + collapsible reconciliation

First-pass information architecture. KPI summary strip and four sub-tabs replace the single endless column. Bank reconciliation accounts collapse to per-account summaries with bounded internal scroll.

Mockup 2 — Persistent stepper + in-card query expansion

card layout set aside

Promotes the orchestration flow into a persistent top stepper (wayfinding, always visible). Query cards expand in place. The full-width card layout was set aside — it does not scale past ~10 groups.

Mockup 3 — Query master-detail rail

recommended

The chosen query pattern. A scrolling group rail + fixed detail pane. Page height is constant whether there are 4 coarse groups or 43 granular ones; the coarse/granular toggle just repopulates the rail.

Open mockup

These mockups are static design references using placeholder ADMCM data. They render with a light theme and the Tabler icon webfont from a CDN — an internet connection is needed for the icons to appear. The production implementation would inherit the app's existing dark theme and live data.
